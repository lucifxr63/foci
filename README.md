# FOCI – Frontend (Cliente)

Esta es la aplicación cliente del sitio web de **FOCI - Fonoaudiología Clínica Integral**, construida con **React**, **Vite** y **Tailwind CSS**.

Para ver la documentación completa del proyecto, configuración, instalación y cómo iniciar tanto el servidor como la aplicación, dirígete al [README principal de la raíz del proyecto](../README.md).

## 🚀 Inicio Rápido (Frontend)

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar servidor de desarrollo local:
   ```bash
   npm run dev
   ```
   Abierto en: [http://localhost:5173/](http://localhost:5173/)

3. Compilar para producción (carpeta `/dist`):
   ```bash
   npm run build
   ```
